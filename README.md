# Saya no Uta — сайт-визитка

Мой первый сайт, который я делал по визуальной новелле Saya no Uta (она же «Песнь Саи»).
Сначала это была просто страничка «обо мне», но потом я добавил форму регистрации,
музыкальный плеер с саундтреком и немного «мрачных» эффектов на JavaScript.

Сайт полностью статический: только HTML, CSS и JS. Никаких серверов, баз данных и PHP.
Именно поэтому его можно бесплатно выложить на GitHub Pages.

## Страницы

- index.html — главная страница (рассказ о Сае, факты, увлечения, карточки).
- forms.html — страница регистрации (поля: имя, фамилия, телефон, почта, пароль, пол).

## Что интересного внутри

- Адаптив: отдельные стили для планшета и мобильного, на узких экранах меню
  превращается в бургер, карточки становятся вертикальными.
- Музыкальный плеер внизу слева: play/pause, следующий/предыдущий трек,
  перемотка, громкость, повтор плейлиста или одного трека и «лайк».
  Всё сохраняется в localStorage, так что после перезагрузки страницы
  громкость, повтор и лайки остаются на месте.
- «Жуткие» эффекты (creepy.js): глитч заголовков, плавающие частицы
  и шёпоты по краям экрана. Пасхалка: если 5 раз кликнуть по сердечку
  в подвале, на пару секунд откроется «изнанка» с надписью.
- На странице регистрации есть пасхалка в выборе пола.

## Технологии

- HTML5
- CSS3 (Flexbox, медиазапросы для адаптива)
- JavaScript (без библиотек и фреймворков)
- Web Audio API (через обычный тег audio)
- localStorage для сохранения настроек плеера

## Как запустить локально

1. Скачай все файлы в одну папку.
2. Открой index.html в браузере.

НО! если открыть index.html двойным кликом (через file://),
некоторые браузеры могут блокировать загрузку аудио. Поэтому лучше
запустить локальный сервер.

## Как я выкладывал сайт на GitHub Pages

Коротко, потому что я делал это впервые:

1. Создал репозиторий на GitHub.
2. Загрузил все файлы и папку `audio` в корень репозитория.
3. Зашёл в Settings → Pages.
4. Выбрал Deploy from a branch, ветку `main` и папку `/ (root)`.
5. Нажал Save.

Сайт открылся по адресу https://kuber-0.github.io/saya-site
